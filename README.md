## Features

- **Screenshot Intelligence** - Upload conversation screenshots and get instant AI analysis of vibe, interest & strategy
- **AI Wingman** - Witty, Gen Z-fluent AI companion that understands context and gives genuinely useful advice
- **Reply Lab** - Generate perfect replies in 10 different styles (Smooth, Flirty, Funny, Chaotic, Sassy & more)
- **Rizz Progression** - Level up from NPC Energy to RIZZVERSE LEGEND with XP, badges & unlocks
- **Rizz Gym** - Train with realistic scenarios and get AI feedback on your responses
- **Specialized Modes** - Crush Mode, First Move, Dry Texter Rescue, Date Planner & more
- **Daily Challenges** - Earn XP with daily missions and build your streak
- **Leaderboard** - Compete with other Rizzers across the RIZZVERSE
- **Smart Dashboard** - Track your progress, stats, and improvement over time

## Tech Stack

- **HTML5, CSS3, JavaScript** - Pure vanilla, no frameworks
- **WebLLM** - Runs AI directly in your browser (LLaMA 3.2)
- **CSS Animations** - Smooth transitions, glassmorphism, particle effects
- **Responsive Design** - Optimized for mobile, tablet & desktop
- **GitHub Pages** - Deployed statically

## AI Powered

RIZZVERSE uses [WebLLM](https://webllm.mlc.ai/) to run an AI model directly in your browser. No API keys, no backend required. The AI understands conversation context, reads vibes, and generates natural, human-like replies.

## Run Locally

```bash
# Clone the repo
git clone https://github.com/sparshsinghal1618/rizzverse.git
cd rizzverse

# Open with any local server
# Using Python
python -m http.server 8000

# Using Node
npx serve .

# Or just open index.html in browser
```
